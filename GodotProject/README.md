# BUS & COACH SIMULATOR AFRICA — Godot 4

Premier socle 3D du simulateur. Cette version est une scène de démarrage avec un car provisoire construit en primitives 3D.

## Ouvrir le projet
1. Ouvrir Godot 4.
2. Cliquer sur **Import**.
3. Sélectionner le fichier `project.godot` dans ce dossier.
4. Importer puis lancer avec **F6/F5** ou le bouton Play.

## Commandes clavier
- W / flèche haut : accélérer
- S / flèche bas : freiner
- A / flèche gauche : tourner à gauche
- D / flèche droite : tourner à droite

Les boutons tactiles sont intégrés à l'écran pour les essais sur mobile.

## Choix techniques
- Godot 4, renderer Compatibility / OpenGL pour viser les téléphones modestes.
- Écran paysage 1280 × 720.
- Les primitives visibles sont provisoires. Les vrais modèles de cars, roues, intérieurs et environnements seront créés/importés avec Blender.
- Aucun APK ni test sur appareil n'est encore validé.
