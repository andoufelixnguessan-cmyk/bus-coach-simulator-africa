# Realism and quality gates

The game must not be presented as comparable to a polished commercial simulator until it earns that claim through implementation and device testing.

## Driving feel
- Vehicle mass, inertia, braking distance, steering response, suspension, tire grip, and weight transfer must be tuned for a long coach.
- Cockpit and chase cameras must be stable and comfortable.
- Controls must be reachable on common Android screen sizes and avoid system navigation areas.
- Gearbox, engine response, retarder/engine braking, air brakes, and dashboard instrumentation are planned systems; they are not complete merely because the first controller exists.

## World and traffic
- Roads need believable lane widths, road markings, signs, junctions, speed limits, and surface variation.
- Traffic must obey lanes, braking, following distance, intersections, and basic local driving patterns.
- Route scenery must be geographically inspired by West Africa without claiming exact real-world reproduction until mapped and validated.

## Passengers and company
- Boarding, luggage, ticket validation, passenger comfort, timetable, fares, maintenance, fuel, staff, and company finances need complete gameplay loops.

## Performance and testing
- Establish target Android devices and frame-rate budgets early.
- Test thermal behavior, memory, loading times, touch latency, and battery usage.
- Use scalable quality presets and asset LODs.
- Every milestone requires an installable Android build and a repeatable test checklist.

## Current state
This repository currently contains project documentation and starter C# components only. It is not yet a complete Unity project or an installable game.
